# VPS evaluation (reproducible record)

Generated by `./venv/bin/python scripts/vps_evaluation_report.py` → `data/vps_evaluation_report.json`
(offline, seed 42, 2000 bootstrap resamples, ~35 s). The report stores the md5 of its inputs; the
dashboard marks it **STALE** if `vps_scores_v2.csv`, the ground truth or the exclusion file change.
Tests: `tests/test_vps_evaluation_report.py`. Numbers below are from the 2026-10-15 run.

## Cohort and label
90 compounds with an accepted pre-cutoff PD trial; **14 positive** (prevalence 0.156); no
duplicate compounds. Label = continued clinical investigation: a qualifying PD interventional
trial first posted ≥ 2021-01-01 in the ClinicalTrials.gov snapshot queried 2026-10-05, minus
`data/label_role_exclusions.csv` (D-010). **Not efficacy.** Galantamine's label is unresolved (D-011).

## Reproducibility
- Every persisted AUROC in `data/vps_variant_results.csv` is reproduced exactly from
  `data/vps_scores_v2.csv` (6/6).
- The paired bootstrap re-run is bit-identical, and equals the persisted
  `data/bootstrap_ci_equal5d_vs_4d.csv` (closes the CI-reproducibility concern, E-015).

## Fitted (grid-searched) models
In-sample AUROC (weights chosen on all labels; not performance): 4d 0.725, 3d 0.720, 5d 0.774.
Held-out, weights selected on training folds only — 20 repeated 5-fold nested-CV splits
(mean [2.5–97.5 %]): **4d 0.574 [0.459, 0.679]; 3d 0.571 [0.450, 0.654]; 5d 0.648 [0.561, 0.728]**.
Fitting weights does not beat the unfitted models. Percentile ranks and median imputation are
computed on the whole pool (label-free, transductive; TD-036).

## Dimensions, missingness, duplicates
- Spearman correlation between dimension ranks: max |ρ| 0.435 — no pair is redundant.
- Not measured: safety 7 (no FDA label, all negatives), molecular 16 (no ChEMBL target, 2
  positives) → neutral rank 0.5 + flags (D-004); proximity 2 median-imputed.
- **Duplicate evidence (new, TD-038):** 17 pre-cutoff trials are credited to more than one pool
  compound (35 links, 31 compounds). 4 label trials are shared; only one involves a pool compound
  (NCT07207057, a multi-arm platform trial: Terazosin with Telmisartan, which is not in the pool).
  **Investigated 2026-10-14 (D-020):** the clinical rank uses each compound's maximum phase, so
  a shared trial is not counted twice. 16 links are drug-specific arms, 8 combination or
  unverifiable, 11 fail the P1 role criterion (anaesthesia, interaction-study probes,
  concomitant immunosuppression). Excluding those 11 removes 7 negatives from the pool and
  moves 5d AUROC 0.775 → 0.765, almost entirely through the pool change (paired change on the same
  compounds +0.003 [−0.012, +0.019]). This is a measurement correction, not better prediction.
  Not applied: owner decision (sensitivity report `data/td038_feature_role_sensitivity.json`).

## Calibration
Not applicable: VPS is a mean of percentile ranks used for ordering, not a probability, and 14
positives cannot support a credible reliability curve. Never read a VPS value as a probability.

## Temporal validity and incremental value
Not leakage-free (TD-033, B-001, B-002). Without the literature dimension the equal-weight score
stays above chance (0.740 [0.623, 0.855]); proximity + clinical alone do not (0.653
[0.474, 0.816]) (D-012). Agents 10a, 10d and 10e are **not** in VPS and no incremental value is
claimed for them: their coverage (1, 4 and 4 compounds with outcome-level evidence) is far
too thin for a controlled comparison on 90 compounds / 14 positives.

## Verified formula and baseline (2026-10-15, D-024)
An independent re-implementation (`scripts/vps_verify.py`) reproduces the published baseline: every
rank, score, flag and label for all 90 compounds, max |diff| 2.2e-16. It does not import stage 06.
It runs as a test and as the publication gate of `scripts/run_stage.py 06`.

**Rank of each dimension.** Percentile rank: the average 1-based rank divided by the number of
measured compounds, with ties averaged.

| Dimension | Source | Direction |
|---|---|---|
| proximity | `proximity_z` | lower is better: 1 − rank |
| clinical | maximum phase rank (NA 0 … PHASE4 5) over pre-cutoff trials | higher is better |
| literature | `effective_independent_count` | higher is better |
| safety | `serious_term_count` + 5 × boxed warning, labelled compounds only | lower is better: 1 − rank |
| molecular | `molecular_plausibility_score`, compounds with ≥ 1 target only | higher is better |

**Missing values.**
- Proximity, clinical and literature are median-imputed before ranking. Today this applies only
  to proximity, for Deferiprone and Trimethobenzamide. Current stage-06 code flags this in `dimensions_imputed`,
  but the **approved** `data/vps_scores_v2.csv` (written 2026-10-14) predates that column, so in the approved file
  the two imputed values are unflagged and counted in `n_dimensions_measured` (correction 2026-10-21;
  `scripts/vps_verify.py` reports them as `median_imputed_unflagged`).
- Safety without a label and molecular without a target get 0.5 and are flagged in
  `dimensions_missing` (D-004).

**Scores.**
- `VPS_equal` = mean of the first four ranks.
- `VPS_equal_5d` = mean of all five.
- Labels are attached after all feature steps and come only from the ground truth minus
  `label_role_exclusions.csv`.

**Defects found and fixed (no published score changed):**
1. A duplicated input row silently duplicated a candidate. It now raises.
2. ±inf was ranked as the best or worst value. It is now treated as not computed.
3. Median-imputed proximity looked measured (`n_dimensions_measured` was 5 for 2 compounds).
   A new `dimensions_imputed` flag fixes this.
4. The evaluation report fingerprinted 3 of its 7 inputs. It now fingerprints all of them.

**Open convention question (TD-040, owner decision).** The "legacy" ranks are asymmetric:
higher-is-better dimensions span [1/n, 1] and lower-is-better ones [0, 1−1/n], so the neutral 0.5
is not the midpoint of either. The "midrank" convention ((rank − 0.5)/n, mirrored) fixes this. It
is implemented, verified and run to `data/_candidates/vps_midrank/`:
- max score shift 0.0025;
- 5 adjacent rank swaps, all between drugs with and without a molecular value;
- AUROC 5d 0.7754 → 0.7744;
- AUPRC 0.4243 → 0.4227;
- 4d unchanged.

The published baseline stays "legacy".
